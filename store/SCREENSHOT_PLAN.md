# Store screenshot plan

Use a clean browser profile with no unrelated extensions or personal data. Capture the real packaged extension; do not use mockups as evidence of functionality.

## Chrome Web Store

Export full-bleed PNG or JPEG images at 1280×800 pixels (preferred) or 640×400 pixels:

1. PageStitch popup beside the Chrome toolbar, showing Full page, Visible area, and Select an area.
2. A capture in progress on the neutral tall-page fixture, with progress visible.
3. The finished editor showing crop and annotation tools on the captured fixture.
4. The local library showing two non-sensitive fixture captures.
5. The export panel showing PNG, JPEG, and PDF choices.

The required 440×280 small promotional tile is already available at `store/assets/chrome-small-promo.png`. Its abstract document-stitching artwork makes no feature claims beyond the extension's actual purpose.

## Opera Add-ons

Capture separate Opera screenshots at the preferred 612×408 pixels, never larger than 800×600:

1. PageStitch's location in the default Opera toolbar and its capture menu.
2. PageStitch interacting with the neutral tall-page fixture.
3. The PageStitch editor with its main tools visible.

Use a white-background page, Opera's default interface, and no unrelated extension icons. Center and crop only enough to keep PageStitch and the relevant webpage interaction clear.

## Safety

- Use repository fixtures or a page created specifically for screenshots.
- Do not show real email, authentication, payment, health, customer, or employee data.
- Do not add awards, ratings, user counts, trademarks, or comparisons that cannot be substantiated.
- Ensure English and Russian screenshots match the features described by each localized listing.
