# PageStitch privacy policy

PageStitch processes screenshots entirely inside the Chromium browser.

- No account is required.
- No analytics or telemetry is collected.
- No screenshot, page URL, title, or annotation is uploaded.
- No remote code is loaded.
- Captures are stored locally in the extension's IndexedDB history and are removed when the user deletes them or when the configured history limit is exceeded.
- Settings are stored through Chromium's extension settings storage and may sync through the user's browser account if browser sync is enabled.

PageStitch requests only capabilities required for capture, local processing, clipboard copy, downloads, settings, keyboard/context-menu actions, and large local screenshots. It does not request persistent access to every website.
